## 💫 Overview

**Math Beats Asteroids** is an educational arcade game that combines fast-paced space combat with mathematical problem-solving. Inspired by classic arcade games, players must solve math equations quickly to destroy incoming asteroids and survive increasingly challenging waves.

The goal is simple: **think fast, solve correctly, and blast your way through space.**

Instead of relying only on reflexes, this game challenges players to combine:
- 🧠 Mathematical reasoning
- ⚡ Quick decision-making
- 🎯 Accuracy under pressure
- 🚀 Arcade-style gameplay

Math becomes a tool for progression rather than just a classroom exercise.

---

# 🎮 Gameplay

Players control a spaceship defending against waves of incoming asteroids.

Each asteroid contains a mathematical challenge. To destroy it, players must:

1. Read the displayed equation
2. Calculate the correct answer
3. Enter the answer before the asteroid reaches the ship
4. Earn points for successful hits

Correct answers destroy asteroids and increase your score.

Incorrect answers or slow responses allow asteroids to continue advancing.

# 🚀 Installation & Setup

## 1. Clone the repository

```bash
git clone https://github.com/yourusername/math-beats-asteroids.git
```

## 2. Navigate into the project folder

```bash
cd math-beats-asteroids
```

## 3. Install dependencies

Install Pygame:

```bash
pip install pygame
```

## 4. Run the game

```bash
python main.py
```
